# federation-agent

Governed orchestrator-federation domain for bounded competition rounds, explicit budgets, independent referees, and evidence-backed winners.

Canonical authority is `.pmcro`. `.agents` projects it. Host directories mirror `.agents`.
The autonomous PMCR-O loop never blocks on a clarification question: it resolves from validated
context or records HALT. Domain scripts are the same entrypoints used by an agent and by a human terminal.
